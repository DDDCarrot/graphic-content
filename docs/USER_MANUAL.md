# Graphic Content Generator - User Manual

Welcome to **Graphic Content**, a modern tool for converting long-form text into beautiful, shareable images.

## Getting Started

1. **Access the Application**: Open the web application in your browser.
2. **The Interface**:
   - **Left Panel**: Controls for text input, template selection, and configuration.
   - **Right Panel**: Live preview of your generated images.

## Features & Usage

### 1. Input Text
- Locate the **Input Content** text area in the top-left section.
- Type or paste your text. The application supports long paragraphs and will automatically handle formatting.
- You can see the character count and the number of images generated below the text area.

### 2. Choose a Template
- Browse the **Choose Template** section.
- Click on a style card to apply it immediately.
- Available styles include:
  - **Classic Minimal**: Clean white background, perfect for professional use.
  - **Modern Dark**: High-contrast dark mode.
  - **Soft Gradient**: Gentle colors for a friendly vibe.
  - **Nature Card**: Earthy tones.
  - **Tech Blue**: Professional blue accent.

### 3. Configuration
Customize your output in the **Configuration** panel:

- **Generation Mode**:
  - **Single Image**: Tries to fit all text into one long image. Good for short posts.
  - **Multi-Page**: Automatically splits long text into multiple images (carousel style).
- **Image Width**: Slider to adjust the width of the output image (640px to 1920px).
- **Max Characters per Image**: (Multi-mode only) Controls how much text fits on one slide before creating a new one.
- **Emoji Decoration**: Add an emoji that will be placed according to the template style (e.g., top-right corner).

### 4. Download Images
- **Download Single Image**: Hover over any image in the preview area and click "Download this".
- **Download All**: Click the "Download All" button at the top of the preview area to save all generated images.

## Tips for Best Results
- Use double line breaks for paragraph spacing.
- Adjust "Max Characters per Image" if your text looks too crowded or too sparse.
- Try different templates to match the tone of your content.
